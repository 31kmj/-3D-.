# 공간자료 출처와 이용조건

`scene_context.json`은 OpenStreetMap 기여자의 공개 데이터를 가공한 공간 DB다. 원본은 프로젝트의 `01_Research/raw/`, 가공 GeoJSON과 품질 메타데이터는 `01_Research/processed/`에 있다.

- Attribution: © OpenStreetMap contributors.
- 데이터 라이선스: Open Data Commons Open Database License 1.0 (ODbL).
- 안내: https://www.openstreetmap.org/copyright
- 라이선스 원문: https://opendatacommons.org/licenses/odbl/1-0/
- 이 가공 공간 DB는 ODbL 1.0으로 제공한다. 웹사이트 코드, 사용자 문서 및 별도 출처 교량 정보의 이용조건은 각각 구분한다.
- 지도 화면에는 출처와 ODbL 링크를 표시한다. 후속 배포에서도 표시와 자료별 조건을 유지한다.
- 교량 제원과 도면거리 출처: 서울시설공단 청계천 공식 안내 페이지. 페이지의 공공누리 출처표시 표식을 확인했다. 개별 출처 URL은 연구 보고서와 데이터에 포함했다.

OSM의 원래 높이 태그와 추정 높이는 구분한다. 실제 지형 표고, 산책로/계단/교량 높이, 포장·창문·난간 외관 및 수위/위험/경로는 검증된 현장 자료가 아니다.
