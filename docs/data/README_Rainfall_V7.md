# V7 과거 강우자료와 이용조건

출처: 서울특별시, 서울시 강우량 정보 OA-1168. https://data.seoul.go.kr/dataList/OA-1168/F/1/datasetView.do . **공공누리 제2유형: 출처표시·상업적 이용금지**. 본 로컬 비상업 졸업작품에서 이용하며 향후 상업/B2G 권리를 확보한 자료라고 간주하지 않는다.

`rainfall_v7.json`은 공식 2026년8월 CSV 214,209행에서 종로구청1001·중구청1101을 추출했다. 전체 원본48코드와 카탈로그47개소 차이는 원인 미확정이다. 각 관측소 4,464개 완료10분 구간이다. 시각 HH:09는 카탈로그 예시상 HH:00:00~HH:09:59를 나타낸다. 값은 해당 구간 우량mm이며 mm/h가 아니다.

1/3/12시간량은 연속6/18/72개 합이다. 누락·충돌·초기 이력 부족은 null, 관측0은0이다. 현재 날씨·유역 평균·수위·침수 깊이·안전도·대피 판단을 나타내지 않는다. 원본과 다운로드 폼/해시는 `01_Research/version-7/rain_download_manifest.json`, 처리기는 `06_Simulation/build_rainfall_v7.py`, 검증은 `verification_version-7/`에 있다. 센서 검교정과 독립 QC는 미확보.

강우량계 위치 부속파일은 확보했으나 PRJ가 없는 SHP와 좌표 의미의 확인이 남아 실제 변환/최단거리 관측소 선정에 사용하지 않았다. 별도 현장 및 수리모형 검증 없이 강우에서 실제 수위나 침수 위험을 추정하지 않는다. 기상청 예상 강수 특보 기준과 과거 통제 공지는 설명용 참고이며 자동 통제 임계값이 아니다.
